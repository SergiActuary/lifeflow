Project life-insurance cash flows and compute the reserves. Write your own flows as plain Python; LifeFlow vectorizes them across the whole portfolio as N × T grids and compiles the hot paths with numba.

How it works

Every flow is an N × T matrix — one row per policy, one column per period — and two tools build them.

Objects: the fixed maths

Portfolio, Timeline, Decrement and Probabilities handle the calculations that are identical for any portfolio — in-force and exit-by-cause probabilities. Set them up once and reuse them everywhere.

Decorators: your freedom

With the @grid decorator you write a flow's value for one policy at one instant, in plain Python. It broadcasts that into the full N × T matrix — you keep total freedom to define your own flows while the grid is built for you.
